GLÜCKSTAL

The website of a small handmade leather workshop in Novosibirsk — wallets, card holders, bags and belts, hand-stitched to order. Open-source code: a bilingual catalog, orders delivered to Telegram and an admin panel where the owner manages everything on the site.

Visit the website → Русская версия Source code on GitHub

What the site does

Catalog

One-page catalog with categories, gift filters, product galleries with swipe and deep links to every product.

Orders to Telegram

The order form saves every request and sends it to the owner's Telegram. Spam traps, rate limits and a relay option for regions where Telegram is blocked.

Two languages

Russian and English versions with hreflang and separate URLs. Every text in the catalog has an English twin, with a Russian fallback.

SEO

Editable meta tags, generated Open Graph images, schema.org Store and Product markup, sitemap and robots.txt.

Admin panel

Dashboard

Visits, unique visitors, time on site, orders, conversion, sources, devices, and the latest visits with IP and device.

Everything is editable

Products and photos, prices, “About me”, contacts, reviews, FAQ, hero texts and images — no code changes needed.

Telegram login

Link an admin account to Telegram once, then log in with the Telegram Login Widget.

Backups

One-click export of the database and photos, safe import with integrity checks and automatic snapshots.

Stack

  • Python 3.12 · Django 5.2 · SQLite · Pillow · Gunicorn · WhiteNoise
  • Vanilla JS and CSS, no build step
  • Docker Compose behind nginx with Let's Encrypt
  • Test suite covering content management, uploads, orders, the bot and backups: python manage.py test shop
